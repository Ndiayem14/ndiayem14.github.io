# Moustapha Ndiaye Portfolio

Personal portfolio for Moustapha Ndiaye, Software Developer and Product Manager.

## Run it locally
Open `index.html` in your browser, or in VS Code install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.

## Add your photo
Save your photo as `images/profile.jpg` (a square or portrait headshot works best).

## Publish with GitHub Pages
1. Push this folder to a GitHub repository.
2. In the repository, go to **Settings > Pages**.
3. Under **Source**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/` in a minute or two.
